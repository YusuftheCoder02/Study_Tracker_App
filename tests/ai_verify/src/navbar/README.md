## Provided setup

- `index.html` provides the page shell, React runtime, and stylesheet link.
- `app.jsx` provides only an empty React app mount point.
- `styles.css` provides a minimal page reset and font.
- This setup is infrastructure, not evidence that React or layout skills are verified.

The React and JSX runtime load from a CDN, so opening `attempts/attempt-1/index.html` requires an internet connection.
