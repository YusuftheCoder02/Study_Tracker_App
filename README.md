# Study Tracker

A personal study-tracking web app and a long-term project for learning JavaScript by building something useful.

## Project goal

Study Tracker will grow alongside my development skills. The first version is deliberately being built with **HTML, CSS, and vanilla JavaScript**—without frameworks or a backend. The focus is not just finishing an app; it is understanding how each part works and building it one step at a time.

## Current status

This project is at the beginning of development. The initial milestone is a desktop interface where a user can enter a task, add it, and see it appear in a task list. Features in the roadmap below are planned, not necessarily implemented yet.

## Planned features

- Add and manage study tasks
- Mark tasks complete, edit them, and delete them
- Organize tasks into **DePaul** and **SDL** categories
- Filter tasks by category and view task statistics
- Save tasks in the browser with `localStorage`
- Track study sessions, including subject, category, duration, and date
- Add responsive layouts after the core desktop experience works

## Learning roadmap

1. Build a static HTML interface and a usable desktop layout.
2. Add basic JavaScript interactions, starting with adding a task.
3. Represent tasks with JavaScript objects and arrays.
4. Implement task management and categories one feature at a time.
5. Add filtering and statistics.
6. Learn JSON and `localStorage` to persist data between visits.
7. Add study-session tracking.
8. Improve the layout for phones and other screen sizes.
9. Refactor and learn JavaScript modules when the project is ready.
10. Finish and deploy the vanilla JavaScript version.

## Technology

- HTML
- CSS
- Vanilla JavaScript

Frameworks, server-side technologies, and databases are intentionally out of scope for this first version. They may be explored in later versions after completing the vanilla JavaScript app.

## Run locally

There is no build step or package installation planned for this version. Once the interface is in place, open `index.html` in a web browser to use it. During development, a code editor's built-in local preview is also suitable.

## Project principles

- Build one feature at a time.
- Try an implementation before reaching for a complete solution.
- Learn the specific concept needed to move forward, then apply it in the project.
- Test changes and commit completed milestones.
- Keep the first version focused on the current learning stage.

## Looking ahead

The longer-term direction is to use this project to progress from vanilla JavaScript to React, then explore a Node.js backend, an API, and a database. Those technologies belong to future learning stages—not this first version.
